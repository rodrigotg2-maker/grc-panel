# GRC · Panel de avance

Panel del avance del desarrollo del juego GRC, diseñado con Claude Design.

**Una sola URL:** https://rodrigotg2-maker.github.io/grc-panel/ — detecta el dispositivo y carga la vista móvil (aplicación, instalable) en celulares o la vista web en computadores. Para forzar una: `?vista=movil` o `?vista=web`.

- `movil/` y `web/`: las páginas de Claude Design, sin modificar.
- `estado.json`: se regenera automáticamente desde el plan del proyecto. No contiene código del juego.
