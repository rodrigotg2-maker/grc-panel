# GRC · Panel de avance

Panel del avance del desarrollo del juego GRC, diseñado con Claude Design.

- Vista móvil (aplicación, instalable): https://rodrigotg2-maker.github.io/grc-panel/
- Vista web: https://rodrigotg2-maker.github.io/grc-panel/web/

Las páginas leen `estado.json`, que se regenera automáticamente desde el plan del proyecto. No contiene código del juego.
